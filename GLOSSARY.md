# co

co is a terminal coding agent. A person talks to a model, the model calls tools, and the conversation stays on screen.

## Language

**Call summary**:
The one-line header for a tool call: which tool ran, and the short form of its arguments.
_Avoid_: tool detail, tool label

**Tool result**:
The text a tool returned to the model.
_Avoid_: tool output, tool response
